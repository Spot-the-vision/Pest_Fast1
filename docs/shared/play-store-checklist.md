# Play Store Launch Checklist

- [ ] Data safety form completed (matches `security-privacy.md` — what's collected,
      what's shared, retention/deletion policy)
- [ ] Privacy policy published and linked in-app and in the store listing
- [ ] Account/data deletion flow implemented and reachable from within the app
- [ ] Content rating questionnaire completed
- [ ] Target API level meets current Play requirements
- [ ] Signed release build (EAS build) tested on a physical device
- [ ] Crash reporting / monitoring wired up before launch
- [ ] Store listing: screenshots, short/long description, feature graphic
- [ ] Separate listings planned for customer-app and worker-app (two apps, two
      listings)
- [ ] Payment flow (UPI) tested end-to-end in production mode, not sandbox, before
      submission
